# IdeaFlow Specifications Overview

## Purpose

This folder contains detailed specifications for features and components. Each spec is created before implementation and updated after.

## Spec Template

When creating a new spec, use this structure:

```markdown
# [Feature Name] Specification

**Status:** Draft | Approved | Implemented | Deprecated
**Created:** YYYY-MM-DD
**Updated:** YYYY-MM-DD

## Overview

Brief description of what this feature does.

## Requirements

### Functional Requirements
- FR1: ...
- FR2: ...

### Non-Functional Requirements
- NFR1: ...

## Technical Design

### Components Affected
- List of files/components

### Data Model Changes
- Any schema changes

### API Changes
- New or modified endpoints

## User Experience

### User Flow
1. Step 1
2. Step 2

### UI Mockups
(If applicable)

## Acceptance Criteria

- [ ] Criterion 1
- [ ] Criterion 2

## Open Questions

- Question 1?

## Implementation Notes

(Added after implementation)
```
