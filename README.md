# IdeaFlow

A phone-first PWA for capturing and developing ideas with AI assistance.

## What It Does

- **Capture ideas fast** - Voice or text, fire-and-forget
- **AI fleshes them out** - Background analysis while you go about your day
- **Review and refine** - Come back to a full analysis, chat with AI to go deeper
- **Decide** - Pursue or defer, stay organized

## Tech Stack

- React + TypeScript (Frontend)
- Node.js/Express (Backend)
- PostgreSQL (Database)
- Claude API (AI)
- Replit (Hosting, Auth, Infrastructure)
